## SAM10 Semester Plan · AWS Cloud Foundations + Cloud Operations

The 15-week semester is structured as **one AWS training module per week**
(Cloud Foundations for the foundational half, Cloud Operations for the advanced half).
Each lab in **Part V** is aligned to a single module — you complete the Skill Builder
module + a short hands-on activity, file a small artifact, and answer checkpoint questions.

Weeks 1–2 (Cloud Foundations Modules 1–2) are **already completed**.

### How it works
- **Each lab** ≈ 2–3 hours: watch the assigned module (≈45 min quiz + content),
  run the short hands-on activity, file the artifact, answer 5 checkpoint questions.
- **Artifact** = the single piece of evidence you submit (table, brief, screenshot,
  or diagram). Heavy CLI is removed; each lab keeps only the commands that *prove* the
  concept you just learned in the module.
- **GreenGrid** is no longer the running scenario — modules are self-contained so the
  semester doesn't depend on one long lab surviving AWS account changes.
